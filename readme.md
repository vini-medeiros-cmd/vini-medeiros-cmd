# Vinícius Medeiros

**Engenheiro de Software** · Automação de Processos · Integração de Sistemas · Back-end & IA Aplicada

Construo sistemas que eliminam trabalho manual - desde automações internas até integrações entre plataformas corporativas. Combino capacidade técnica (Python, APIs REST/SOAP, Flask) com visão de negócio e gestão de KPIs, transformando processos manuais em soluções escaláveis, documentadas e orientadas a dados.

Atuo há quase 10 anos em TI, atualmente como **Líder de SAC | Processos e Sistemas** numa empresa de gestão em saúde ocupacional, onde lidero a estruturação de processos e a implementação de automações internas. Em paralelo, mantenho um portfólio de projetos pessoais em produção real - de um agregador de vagas rodando numa VPS gratuita da Oracle Cloud a um board Kanban colaborativo em Next.js/Supabase - expandindo ativamente para full stack e automação aplicada com IA (n8n, MCP, agentes).

## O que eu construo

| Área | Exemplos |
|---|---|
| **Automação** | Scripts em Python que eliminam tarefas manuais e repetitivas, com credenciais e configuração isoladas em `.env` |
| **Integração de sistemas** | Conectores entre APIs corporativas — REST e SOAP/WebServices, ERPs e CRM |
| **Back-end** | Plataformas web internas com Python/Flask, PHP e Node.js; APIs e banco (Postgres/SQLite) com Supabase |
| **Front-end / Full stack** | Interfaces com HTML/CSS/JavaScript puro, React e Next.js, incluindo apps mobile empacotados com Capacitor |
| **Automação com IA** | Workflows em n8n, integração com a API da Claude, servidores/clientes MCP |
| **BI & Dados** | Dashboards, KPIs e indicadores operacionais no Power BI |
